# EI SIMULATOR

> This Flutter project is the course output for Mobile Programming 2. demonstrating local data persistence using SQLite (via the `sqflite` package) and implements basic CRUD (Create, Read, Update, Delete) operations plus simple search functionality.

**Tech / Dependencies**
- Flutter (stable channel)
- `sqflite`: SQLite plugin for Flutter
- `path_provider`: locating platform-specific directories (commonly used with `sqflite`)

**Run locally**
1. Install Flutter and ensure it is on your PATH.
2. From the project root run:

```bash
flutter pub get
flutter run -d <device>
```
